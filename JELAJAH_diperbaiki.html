Konsep Struktur Data

1. Array
Variabel daftarTiket menyimpan kumpulan data tiket dalam satu array.

2. Struct
Setiap tiket dibuat sebagai object JavaScript dengan atribut ID, jenis transportasi, asal, tujuan, harga, dan waktu. Object ini menyerupai struct, tetapi bukan struct asli C++.

3. Pointer/Referensi
Variabel pointerTiketAktif menyimpan referensi ke object tiket yang dipilih. JavaScript tidak memiliki raw pointer seperti C++. Contoh pointer asli C++ tersedia di bawah.

Contoh Struct, Array, dan Pointer dalam C++

#include <iostream>
#include <string>
using namespace std;

struct Tiket {
    string id;
    string jenisTransportasi;
    string asal;
    string tujuan;
    int harga;
};

int main() {
    Tiket daftarTiket[2] = {
        {"TKT001", "Kereta", "Surabaya", "Yogyakarta", 180000},
        {"TKT002", "Bus", "Surabaya", "Jakarta", 250000}
    };

    Tiket* pointerTiketAktif = &daftarTiket[0];
    cout << pointerTiketAktif->jenisTransportasi << endl;
    cout << pointerTiketAktif->harga << endl;

    return 0;
}
